# YOLOv8 Object Detection

This project demonstrates basic object detection using a pre-trained YOLOv8 model from Ultralytics.  
The model is used to detect objects in a single image and save the output with bounding boxes.

---

## 📌 Features
- Uses pre-trained YOLOv8 (`yolov8n.pt`)
- Performs object detection on an image (`bus.jpg`)
- Draws bounding boxes with class labels and confidence scores
- Saves the detected output image automatically

---

## 🛠️ Requirements

- Python 3.8 or higher
- ultralytics
- opencv-python
